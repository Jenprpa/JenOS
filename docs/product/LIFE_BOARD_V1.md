# Life Board v1

Status: Implemented for Sprint 2.2 Owner Pilot

## Product Intent

The Life Board is an owner-facing view of current structured reality.

It should feel like:

```text
นี่คือโลกของฉันที่ถูกจัดไว้แล้ว
```

not:

```text
นี่คือฐานข้อมูลที่ฉันต้องดูแล
```

## Sections

- ตาราง / การสอน
- สิ่งที่ต้องทำ
- การเงิน
- กำลังรอ
- โปรเจกต์
- ข้อมูล / บันทึก

## Non-Goals

The Life Board is not:

- a new domain concept,
- a dashboard analytics surface,
- a KPI board,
- a productivity score,
- a task backlog,
- a manual maintenance surface.

## Owner Pilot Questions

- Does the board feel organized?
- Can the owner immediately see where information went?
- Is any information unnecessarily duplicated?
- Does the UI feel personal and warm?
- Does maintaining JenOS create extra work?

# Product Vision v0.1

JenOS คือระบบสนับสนุนการตัดสินใจส่วนบุคคล ซึ่งเข้าใจ Project, State, Context, Memory, Constraint และ Human Capacity เพื่อช่วยให้ผู้ใช้เลือกใช้เวลาและพลังกับสิ่งที่มีความหมาย โดยไม่แย่งสิทธิ์การตัดสินใจไปจากผู้ใช้

## Initial User

ผู้ใช้เริ่มต้นคือเจ้าของระบบเพียงคนเดียว: Jen

JenOS จึงควรถูกออกแบบจากชีวิตจริงของผู้ใช้คนนี้ก่อน ไม่ใช่จากสมมติฐานของตลาดกว้าง

หลักการ:

> Build for Jen first, generalize only after evidence.

## Problem

ชีวิตครูและคนทำหลายโครงการพร้อมกันไม่ได้มีแค่ "งานค้าง"

ปัญหาจริงคือ:

- มีหลาย Project ที่เดินพร้อมกัน
- บางเรื่องรอคนอื่น
- บางเรื่องมี Deadline
- บางเรื่องมีความเสี่ยงซ่อนอยู่
- บางเรื่องสำคัญแต่ยังไม่ชัด
- บางเรื่องกระทบสุขภาพ พลังงาน และชีวิตส่วนตัว
- เหตุผลของการตัดสินใจมักหายไปตามเวลา

ระบบทั่วไปมักแสดงรายการงานจำนวนมาก แต่ไม่ตอบว่าควรสนใจอะไรในขณะนี้ และเพราะอะไร

## Product Direction

JenOS ควรช่วยให้ผู้ใช้:

- เห็น Current State ของ Project สำคัญ
- เห็น Next Action ที่มีความหมาย
- เห็น Blocker และ Dependency
- แยกสิ่งที่ควบคุมได้ออกจากสิ่งที่ควบคุมไม่ได้
- รักษา Memory ของ Project
- ตัดสินใจโดยเห็นเหตุผลและความไม่แน่นอน
- ไม่แบกงานที่ยัง Waiting เหมือนเป็น Failure
- ไม่ทำลายสุขภาพเพื่อให้ตัวเลข Productivity ดูดี

## What JenOS Is Not Trying to Be Yet

ในระยะแรก JenOS ยังไม่ควรถูกออกแบบเป็น:

- SaaS สำหรับทุกคน
- Multi-tenant platform
- ระบบองค์กร
- เครื่องมือวัดผลงานพนักงาน
- To-do App หรือ Calendar Replacement

การ generalize ต้องเกิดหลังจากมีหลักฐานว่ารูปแบบใดใช้ได้จริงกับชีวิตของ Jen

## Success Signals for Sprint 0

Sprint 0 สำเร็จเมื่อเอกสารสามารถตอบได้ว่า:

- JenOS เชื่ออะไร
- JenOS ปกป้องอะไร
- JenOS ไม่ควรเป็นอะไร
- Concept หลักมีอะไรบ้าง
- ทำไม Project และ State จึงเป็นศูนย์กลาง
- Today Experience มีหน้าที่อะไรโดยไม่กลายเป็น To-do List

# Today Experience v0.1

Today คือประสบการณ์หน้าแรกเชิงแนวคิดของ JenOS

Today ไม่ใช่ Dashboard รวมข้อมูลทั้งหมด และไม่ใช่ To-do List

คำถามหลักของ Today คือ:

> หากผู้ใช้มีเวลาและพลังจำกัดในขณะนี้ ควรใช้กับอะไรเพื่อให้เกิดผลดีที่สุด โดยไม่ทำร้ายชีวิตส่วนอื่น

## หลักคิด

Today ควรช่วยลดภาระการตัดสินใจ ไม่ใช่เพิ่มรายการให้รู้สึกผิด

ระบบควรคำนึงถึง:

- เวลาที่มี
- พลังงาน
- Deadline
- ผลกระทบ
- ความเสี่ยง
- Dependencies
- Commitments
- สิ่งที่กำลัง Blocked
- สิ่งที่รอผู้อื่น
- สุขภาพและการพัก
- Context ปัจจุบัน

## Section 1: สิ่งที่ต้องตัดสินใจวันนี้

ตอบคำถาม:

- มี Decision ใดที่ถ้าไม่ตัดสินใจวันนี้จะทำให้ Project เสียหายหรือช้าลง?
- Decision นี้เกี่ยวกับ Project ใด?
- ข้อมูลใดเป็น Fact, Assumption, Inference หรือ Unknown?
- มีทางเลือกอะไรบ้าง?
- ถ้าเลื่อนการตัดสินใจ จะเกิดผลอย่างไร?

ใช้ข้อมูลประเภท:

- Decision
- Risk
- Deadline
- Blocker
- Context
- Commitment
- Memory

ต้องหลีกเลี่ยง:

- บังคับให้ตัดสินใจทั้งที่ข้อมูลยังไม่พอ
- เสนอคำตอบเดียวโดยไม่อธิบายเหตุผล
- ทำให้ AI suggestion ดูเหมือนข้อเท็จจริง

## Section 2: สิ่งที่ควรขยับวันนี้

ตอบคำถาม:

- มี Project ใดที่ควรขยับด้วย Action ขนาดเหมาะสมกับเวลาและพลังตอนนี้?
- Action นี้สร้างผลกระทบอย่างไร?
- ทำไมจึงควรขยับวันนี้ ไม่ใช่วันอื่น?
- มีสิ่งใดที่ขยับไม่ได้เพราะกำลัง Waiting หรือ Blocked?

ใช้ข้อมูลประเภท:

- Project
- State
- Action
- Deadline
- Impact
- Effort
- Energy
- Dependency

ต้องหลีกเลี่ยง:

- แสดงรายการงานยาว ๆ
- จัด priority จาก Deadline อย่างเดียว
- ทำให้ Action กลายเป็น Task center

## Section 3: สิ่งที่กำลังรอ

ตอบคำถาม:

- Project ใดกำลัง Waiting?
- รอใครหรือรออะไร?
- รอเพราะเหตุใด?
- ควรตรวจสอบอีกครั้งเมื่อใด?
- ผู้ใช้ควร follow up วันนี้หรือยังควรวางไว้ก่อน?

ใช้ข้อมูลประเภท:

- Waiting
- Person
- Role
- Dependency
- Review Date
- Event
- Commitment

ต้องหลีกเลี่ยง:

- นับ Waiting เป็นงานค้างของผู้ใช้
- ทำให้ผู้ใช้รู้สึกผิดกับสิ่งที่ควบคุมไม่ได้
- ปล่อย Waiting ไม่มี review date

## Section 4: อย่าลืมดูแลตัวเอง

ตอบคำถาม:

- สภาพพลังงานของผู้ใช้ตอนนี้เหมาะกับงานแบบใด?
- มีสัญญาณว่าควรพัก ลดขอบเขต หรือเลื่อนสิ่งใดหรือไม่?
- มีเรื่องสุขภาพ ยา เงิน บ้าน หรือครอบครัวที่กระทบ Project สำคัญหรือไม่?
- การขยับวันนี้ควรจำกัดขอบเขตอย่างไรเพื่อไม่ทำร้ายชีวิตส่วนอื่น?

ใช้ข้อมูลประเภท:

- Energy
- Health-related context
- Personal commitment
- Risk
- Calendar-like context
- Recent workload

ต้องหลีกเลี่ยง:

- ทำตัวเป็น Medical Diagnosis System
- ให้คำแนะนำสุขภาพเกินข้อมูล
- ยก Productivity เหนือสุขภาพ

## Anti-patterns

Today ต้องไม่กลายเป็น:

- รายการงานทั้งหมด
- หน้าแสดงจำนวนงานค้าง
- Dashboard ที่ยัดทุกอย่างไว้พร้อมกัน
- ระบบให้คะแนนชีวิต
- ระบบสร้างความรู้สึกผิด

## OWN-003 Clarification Direction

Batch 3 and Batch 4 show that `Waiting` has at least two distinct realities:

```text
Partial dependency
Project can still move
-> Do not treat whole Project as Waiting.

Total dependency
No meaningful progress remains
-> Project-level Waiting may be truthful.
```

Clarification should preserve the layered state model:

- Observed State
- Suggested State
- Confirmed State

But examples should avoid implying that any unresolved dependency justifies:

```text
Project = Waiting
```

## OWN-010 Clarification Direction

Batch 3 and Batch 4 show that the following are evidence, events, outcomes, or external realities:

- Submitted
- Accepted
- Outcome Known
- Follow-up Done

They may inform completion, but do not universally determine completion.

Completion depends on:

```text
Project Boundary
Owner Responsibility
Owner Judgment
```

Therefore:

```text
Submitted may equal Completed only when the Project boundary ends at submission.

Submitted is not Completed when review, correction, acceptance, follow-up, or owner responsibility remains.
```

# Owner Decision Response Template

ใช้ template นี้ตอบทีละ Decision

```text
Decision ID:
Selected Option:
Custom Decision:
Reason:
Concerns:
Exceptions:
Examples:
Confidence:
Review Date:
```

ค่า Confidence ที่ใช้ได้:

```text
High
Medium
Low
Experimental
```

คำตอบพิเศษที่ใช้ได้:

```text
Deferred — need real-life examples
Experimental — use temporarily and review later
```

## Notes

- ถ้าเลือก option ของ AI ให้ยังถือว่าเป็น Owner Decision เฉพาะเมื่อเจ้าของระบบตอบเอง
- ถ้าไม่แน่ใจ ให้ใช้ `Experimental` พร้อม Review Date
- ถ้าต้องการตัวอย่างชีวิตจริงก่อน ให้ใช้ `Deferred — need real-life examples`
